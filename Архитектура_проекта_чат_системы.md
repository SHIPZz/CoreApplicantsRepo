# Архитектура проекта чат-системы для мультиплеерной игры

## Общая информация

**Время разработки:** 4 часа  
**Тип проекта:** Чат-система с уведомлениями для MOBA-игры  
**Архитектура:** Clean Architecture с применением SOLID принципов  
**Технологии:** .NET 9.0, System.Reactive, Dependency Injection, NUnit, Moq

## Архитектура проекта

### 1. Слоистая архитектура (Layered Architecture)

Проект построен по принципу Clean Architecture с четким разделением на слои:

```
┌─────────────────────────────────────┐
│           Presentation              │
│         (ChatSystem.Demo)           │
├─────────────────────────────────────┤
│           Application               │
│      (ChatSystem.Application)       │
├─────────────────────────────────────┤
│             Domain                  │
│        (ChatSystem.Domain)          │
├─────────────────────────────────────┤
│         Infrastructure              │
│     (ChatSystem.Infrastructure)     │
└─────────────────────────────────────┘
```

#### Domain Layer (ChatSystem.Domain)
- **Entities:** `ChatMessage` - основная сущность сообщения
- **Enums:** `ChatType`, `EventType` - типы чата и событий
- **Interfaces:** Все абстракции для инверсии зависимостей

#### Application Layer (ChatSystem.Application)
- **Services:** `ChatManager`, `ChatMediator` - основная бизнес-логика
- **Builders:** `NotificationBuilder` - паттерн Builder для уведомлений
- **Factories:** `ChatManagerFactory` - фабрика для создания менеджеров

#### Infrastructure Layer (ChatSystem.Infrastructure)
- **Network:** `MockChatNetwork` - имитация сетевого слоя
- **Repositories:** `ChatMessageRepository`, `EventRepository` - работа с данными
- **DI:** `ServiceCollectionExtensions` - настройка зависимостей

#### Presentation Layer (ChatSystem.Demo)
- **Program.cs:** Демонстрация работы системы

### 2. Примененные паттерны проектирования

#### Mediator Pattern
```csharp
public class ChatMediator : IChatMediator
{
    private readonly IChatNetwork _network;
    private readonly IChatMessageRepository _messageRepository;
    private readonly IEventRepository _eventRepository;
    
}
```

**Назначение:** Централизованная маршрутизация сообщений между компонентами системы.

#### Builder Pattern
```csharp
public class NotificationBuilder
{
    public NotificationBuilder SetType(EventType type)
    public NotificationBuilder SetMessage(string message)
    public (EventType, object) Build()
}
```

**Назначение:** Пошаговое создание сложных объектов уведомлений.

#### Factory Pattern
```csharp
public class ChatManagerFactory : IChatManagerFactory
{
    public IChatManager CreateChatManager(string clientId)
}
```

**Назначение:** Создание экземпляров ChatManager с правильной конфигурацией.

#### Observer Pattern (через System.Reactive)
```csharp
public IObservable<ChatMessage> Messages => _messages;
public IObservable<(EventType, object)> Events => _events;
```

**Назначение:** Реактивная обработка событий и сообщений.

### 3. Реактивное программирование

Система использует System.Reactive для обработки потоков событий:

```csharp
private readonly Subject<ChatMessage> _messages = new();
private readonly Subject<(EventType, object)> _events = new();

_manager.Messages.Subscribe(msg => Console.WriteLine($"Received: {msg}"));
_manager.Events.Subscribe(ev => Console.WriteLine($"Event: {ev.Item1}"));
```

**Преимущества:**
- Асинхронная обработка событий
- Автоматическая отписка при Dispose
- Фильтрация и трансформация потоков данных

### 4. Dependency Injection

Настройка DI в `ServiceCollectionExtensions`:

```csharp
public static IServiceCollection AddChatSystem(this IServiceCollection services, int latencyMs = 100)
{
    services.AddSingleton<IChatNetwork>(provider => new MockChatNetwork(latencyMs));
    services.AddSingleton<IChatMessageRepository, ChatMessageRepository>();
    services.AddSingleton<IEventRepository, EventRepository>();
    services.AddSingleton<IChatMediator, ChatMediator>();
    services.AddSingleton<IChatManagerFactory, ChatManagerFactory>();
    return services;
}
```

### 2. Имитируемые функции Photon

#### Broadcast сообщений
```csharp
private void BroadcastMessageIfClientConnected(ChatMessage message)
{
    lock (_lockObject)
    {
        LogMessageBroadcast(message);
        _messageSubject.OnNext(message);
    }
}
```

#### Authority (серверная логика)
```csharp
private bool IsDuplicateMessage(ChatMessage message)
{
    lock (_lockObject)
    {
        var key = CreateMessageKey(message);
        return _processedMessages.Contains(key);
    }
}
```

#### Latency (сетевые задержки)
```csharp
private async Task SimulateNetworkLatencyAsync(CancellationToken cancellationToken)
{
    await Task.Delay(_latencyMs, cancellationToken);
}
```

#### Disconnect/Reconnect
```csharp
public void SimulateDisconnect() => _isConnected = false;
public void SimulateReconnect() => _isConnected = true;
```

#### Unit-тест отправки сообщений
```csharp
[Test]
public async Task SendChatMessageAsync_CallsMediatorSend_WithCorrectMessage()
{
    ChatMessage? receivedMessage = null;
    _manager.Messages.Subscribe(msg => receivedMessage = msg);

    await _manager.SendChatMessageAsync(ChatType.Public, "Hello");

    _mockMediator.Verify(m => m.SendMessageAsync(It.Is<ChatMessage>(msg => 
        msg.Type == ChatType.Public && 
        msg.Sender == "TestPlayer" && 
        msg.Content == "Hello"), It.IsAny<CancellationToken>()), Times.Once());
}
```

#### Тест retry-логики
```csharp
[Test]
public async Task SendChatMessageAsync_OnException_RetriesAfterDelay()
{
    _mockMediator.SetupSequence(m => m.SendMessageAsync(It.IsAny<ChatMessage>(), It.IsAny<CancellationToken>()))
                .ThrowsAsync(new Exception("Network error"))
                .Returns(Task.CompletedTask);

    await _manager.SendChatMessageAsync(ChatType.Team, "Retry test");

    _mockMediator.Verify(m => m.SendMessageAsync(It.IsAny<ChatMessage>(), It.IsAny<CancellationToken>()), Times.Exactly(2));
}
```

#### Тест фильтрации сообщений
```csharp
[Test]
public void GetMessagesByType_ReturnsFilteredMessages()
{
    var publicMessages = new List<ChatMessage>();
    var teamMessages = new List<ChatMessage>();

    _manager.GetMessagesByType(ChatType.Public).Subscribe(msg => publicMessages.Add(msg));
    _manager.GetMessagesByType(ChatType.Team).Subscribe(msg => teamMessages.Add(msg));

    _messageSubject.OnNext(new ChatMessage(ChatType.Public, "Player1", "Public message"));
    _messageSubject.OnNext(new ChatMessage(ChatType.Team, "Player2", "Team message"));

    Assert.That(publicMessages.Count, Is.EqualTo(1));
    Assert.That(teamMessages.Count, Is.EqualTo(1));
}
```

## Потенциальные проблемы и их решения

### 1. Проблемы производительности

**Проблема:** Накопление сообщений в памяти
```csharp
// Решение: Автоматическая очистка
private async Task CleanupOldMessagesIfNeeded(CancellationToken cancellationToken)
{
    await _messageRepository.ClearOldMessagesAsync(TimeSpan.FromMinutes(5), cancellationToken);
    await _eventRepository.ClearOldEventsAsync(TimeSpan.FromMinutes(5), cancellationToken);
}
```

### 2. Проблемы сетевого взаимодействия

**Проблема:** Потеря сообщений при разрыве соединения
```csharp
// Решение: Retry-логика
private async Task SendMessageWithRetryAsync(ChatMessage message, CancellationToken cancellationToken)
{
    try
    {
        await _mediator.SendMessageAsync(message, cancellationToken);
    }
    catch (Exception ex)
    {
        HandleNetworkError(ex);
        await WaitForRetryAsync(cancellationToken);
        await _mediator.SendMessageAsync(message, cancellationToken);
    }
}
```

### 3. Проблемы дублирования

**Проблема:** Дублирование сообщений в сети
```csharp
// Решение: Authority-логика
private bool IsDuplicateMessage(ChatMessage message)
{
    lock (_lockObject)
    {
        var key = CreateMessageKey(message);
        return _processedMessages.Contains(key);
    }
}
```

### 4. Проблемы потокобезопасности

**Проблема:** Конкурентный доступ к общим ресурсам
```csharp
// Решение: Использование lock
private readonly Lock _lockObject = new();

public void AddClient(string clientId)
{
    lock (_lockObject)
    {
        if (!_clients.Contains(clientId))
        {
            _clients.Add(clientId);
        }
    }
}
```

### 5. Проблемы управления ресурсами

**Проблема:** Утечки памяти при подписках
```csharp
// Решение: Правильная реализация IDisposable
public void Dispose()
{
    if (!_disposed)
    {
        _messageObserver?.Dispose();
        _eventObserver?.Dispose();
        _messages?.Dispose();
        _events?.Dispose();
        _disposed = true;
    }
}
```
